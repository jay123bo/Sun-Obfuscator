⬢ 1. Anti Tamper

Runtime integrity. Checks #VM_DATA, header length, debug / hookfunction traps, errors on tamper. Incompatible with Beautify.

● Enabled at 10/10

◉ 2. Hide Globals

Proxy indirection. print / game → _G[ decrypt("...")] via hidden table — no plain globals to scan.

● Enabled at 10/10

⬣ 3. Encrypt Strings

XOR + custom B64. Every literal becomes decrypt("…") with per-file key + shuffled alphabet.

● Enabled at 10/10

⧉ 4. Decompose

Flatten expressions. a = b + c*2 → temps _tmp1, _tmp2 — logic shattered.

● Enabled at 10/10

⟁ 5. Control Flow

State machine. Linear code → while true do if state==1 then … dispatcher with opaque predicates.

● Enabled at 10/10

# 6. Mangle Numbers

Equations. 123 → (0x7B) or (100+23) or (75*2-27) — never plain.

● Enabled at 10/10

◐ 7. Mangle Booleans

Comparisons. true → (1==1), false → (1~=1) sprinkled with not.

● Enabled at 10/10

✎ 8. Rename Variables

Meaningless. Locals → _0xA1B2C3 — stack traces and analysis useless.

● Enabled at 10/10

≡ 9. Minify

Shrink & hide. One-line VM, no comments/WS. Beautify auto-off when Anti-Tamper is on.

● Enabled at 10/10

How 10/10 works — pipeline

1

AST transforms (9 passes)

Rename → Hide Globals → Mangle Booleans/Numbers → Decompose → Control Flow → Encrypt Strings → Anti-Tamper header. Every pass keeps runtime identical.

2

Cipher VM sealing

Transformed source is UTF-8 encoded, split into 22-byte shards, layered: rolling XOR + additive (+i) + reverse+xor, then custom B64 with shuffled alphabet. Random keys per build.

3

Obfuscated loader

Random _0x… locals, junk opaque predicates, integrity checks, (loadstring or load) indirection, optional minify. One file, Luau ready.

4

Vercel static

No server. All crypto runs in your browser. Deploy in one click — edge-cached, private, instant.

FAQ • Vercel • Sun → Cipher

Sun → Cipher — what changed?

Full rebrand + fixed btoa Unicode crash, added 9 AST passes, new yellow/navy design, Vercel-ready static export. Sun V4 was 1 layer; Cipher is 3 + AST.

Why 10/10 is larger?

Every technique adds bytes (string tables, state machine, temps). Max protection ≈ 2.2–4× size. Use Paranoid 9/10 for balance, Maximum for paid scripts.

Vercel deploy?

Push to GitHub → vercel.com/new → Import → Deploy. Or click ▲ Deploy on Vercel above. No vercel.json needed, but one is included for clean URLs.

Can I beautify + anti-tamper?

No — per spec they’re mutually exclusive. Toggling Anti-Tamper auto-disables Beautify to keep integrity checks valid.
